## 📌 Project Overview

This system was built for Norris Hospital (Pvt) Ltd, a private hospital in Colombo with over 50 employees. The system addresses key issues in manual hospital processes, enhances coordination, ensures data security, and delivers better patient outcomes.

## 🎯 Goals & Objectives

**Goals:**
- Enhance patient care
- Automate hospital workflows
- Ensure data accuracy and security
- Foster departmental collaboration

**Objectives:**
- Digitalize medical and administrative processes
- Reduce operational costs
- Improve communication across departments
- Offer user-friendly appointment and record management



## 🛠️ Tech Stack

| Layer         | Technology             |
|---------------|------------------------|
| Frontend      | React.js               |
| Backend       | Node.js + Express.js   |
| Database      | MongoDB (Mongoose)     |
| Authentication| JWT, bcrypt            |
| Tools         | Postman, VS Code, Git  |

## 🧠 Why MERN?

- **MongoDB**: NoSQL flexibility for dynamic healthcare data
- **Express.js**: Robust API handling and middleware support
- **React.js**: Fast, modular frontend for dynamic interfaces
- **Node.js**: Scalable backend for handling real-time requests
  

## 🧩 System Modules

### 🔹 Inventory Management System
- CRUD for medicines/equipment
- Low stock alerts
- QR code support
- PDF/Print report generation

### 🔹 Billing & Invoicing System
- Cost breakdown for treatment & medicines
- Payment processing (cash/card)
- Transaction search and reporting

### 🔹 Patient Medical Records System
- Add/view/update/delete medical records
- Doctor/Admin roles
- Report generation and printing

### 🔹 User Management System
- Role-based registration (Admin, Doctor, Staff, Patient)
- Login authentication with JWT
- Profile & access management

### 🔹 Appointment Management System
- Schedule/reschedule appointments
- Calendar integration
- Patient/Doctor portal

### 🔹 Staff & Payroll Management
- Salary calculation (basic + allowances - taxes)
- CRUD operations for salary records
- Report printing and searching

### 🔹 Internal Messaging System
- Secure chat between doctor, admin, nurse
- Chat history
- Message CRUD operations
